# 冯佳炜个人网站原型

这是一个本地响应式单页原型，定位为“AI 工具能力 × 业务执行能力”的成果证据站。

直接打开 `index.html` 可以浏览；使用本地服务器打开时交互更稳定。

## 当前内容

- 首屏：跑马灯大字 + 镀铬 FJW 字标 + 深蓝云层背景（纯 CSS 生成，无外部素材、无版权风险）
- 证据索引、逐词浮现的引言
- 个人 AI 公众号、均瑶集团、迪美健身案例
- 健身小程序、左联知识库项目
- 求职方向与联系方式

### v4 相对 v3 的校准点（逐项对照参考站抓取产物）

- **色板精确化**：引入参考站 `:root` 测量值——宝蓝 `#03049c`、米黄 `#bab5a6`、浅蓝 `#9fe4f3`、信号绿 `#0f0`、深底 `#1a1a1a`、中灰 `#71737d`，替换原先的近似色
- **CRT 参数对齐**：移动黑带 8s 行程改为 110vh→-200vh；细扫描线间距 .4vw、整体透明度 .25、steps(60)；噪点抖动改 .5s steps(1) 十帧
- **导航体系**：顶部发际线（左右 3vw）；导航链接改压缩展示体；末尾 CTA 加左边框分隔 + REC 绿点三重辉光前置
- **移动端菜单**：黑色遮罩 → 宝蓝全屏面板（88svh）+ clip-path 自上而下展开 + 42px 压缩体大写链接 + 可点击关闭的黑色背板
- **节头布局**：桌面端改左 1/3 编号标签 + 右 2/3 标题的双列 grid（参考站 layout__third/second 体系），移动端回退单列
- **乱码解码特效**：`[data-scramble]` 元素进入视口时字符从随机符号逐位还原（对应参考站 titleRandom），650ms、左→右
- **跑马灯滚动淡出**：首屏跑马灯随滚动透明度/位移淡出（`--fade` 变量由 JS 驱动）
- **大按钮组件**：引言区新增丸形边框按钮（hover 深色填充从左扫过 + ↗），对应参考站 button__big
- **适合方向区**：三列卡片 → 蓝底编号横行（Nº 左列 + 标题 + 等宽描述，上下发际线），hover 浅蓝反色 + 缩进
- **页脚巨型字标拖尾**：FJW 实心 + 三层描边副本，按滚动进度上移错位（`--trail` 变量驱动），对应参考站 footer logoStack
- **首屏渐变**：锚点色改为 `#0eaebc → #003c6a → #022a47`（100deg）
- 未复制参考站的商业字体文件（Graphik / SemiSqueezed / PP Neue Montreal 为付费授权）与图片素材，全部用系统字体栈与纯 CSS 生成的等效质感

三个版本的同目录完整备份都在 `tmp\个人网站原型-v1档案风备份\`（备份时刻为 v2 完成后；v1 的三件套也在其中）。

### v3（pxpush.com 风格移植）要点

- **CRT 复古显示器质感**：全局扫描线 + 屏幕暗角（纯 CSS 覆层，`pointer-events: none`，不影响交互）
- **首屏**：深蓝云层渐变、巨型跑马灯（`● 成果档案 ● EVIDENCE ARCHIVE …`）、镀铬斜体 FJW 字标（银色渐变 `background-clip: text`）
- **导航**：`feng jiawei®` 小写字标 + 绿色状态圆点；`mix-blend-mode: difference` 让导航文字随底色自动黑白反转
- **编辑部分节体系**：`● Nº001 / 引言` ～ `● Nº005 / 联系` 等宽字标签 + 大号箭头
- **引言逐词浮现**：**与滚动进度实时联动**——滚到哪里亮到哪里，往回滚会重新变灰（JS 按段落位置逐帧计算，保留 `<mark>` 高亮），尊重系统「减弱动态效果」设置
- **关键词高亮扫入**：`mark` 关键词亮起时黄色荧光块从左向右擦入（`background-size` 过渡）
- **导航中央镀铬字标**：滚动超过首屏 55% 后，小号斜体 FJW 银色字标浮现于导航栏中央（对应 pxpush 的 px 椭圆标）
- **左下角滚动追踪卡片**：显示当前小节（`Nº00X / 名称`），配色随分区自动切换——灰区黑卡、黑区白卡、蓝区荧光黄卡
- **配色节奏**：蓝（首屏）→ 灰（引言/经历）→ 黑（项目）→ **宝蓝（适合方向）**→ 黑（联系/页脚），复刻参考站的分区节奏
- **行式链接 hover 反色**：灰底上悬停变黑底白字，黑底上悬停变白底黑字，并带左移缩进
- **灰蓝 / 纯黑分节交替**：代表经历灰底；项目实践黑底，含 `FJW · WORKS` 描边幽灵字
- **行式链接**：联系区「发送邮件 ↗」「复制邮箱 ⧉」为横线分隔的全宽行，hover 荧光黄反色
- **黄色荧光笔高亮**（`mark`）与等宽电报体（`V.2027 ---- WELCOME ---- //`）贯穿全站
- 移动端：汉堡菜单 + 黑色全屏遮罩目录
- 字体全部使用系统字体栈（Helvetica Neue / PingFang / 微软雅黑 + 等宽栈），**无外部字体、视频、图片依赖**
- v2 的深浅色切换与打字机、刮擦视频随旧风格移除（CRT 为单一主题）

## 2026-08-27 源码校准（基于 pxpush-frontend 抓取产物）

拿到参考站完整生产构建后，按真实实现做了第二轮校准：

- **精确色板**（来自其 `:root` 变量）：宝蓝 `#03049c`、灰 `#bababa`、黑 `#111`、绿点 `#0f0` 三重辉光
- **CRT 四层体系**（原站为噪点图 + 双扫描线 + gloom 模糊 + crt.png 暗角）：
  1. 细扫描线：5px 间距、`steps(60)` 每秒抖动闪烁
  2. 移动亮带：2–3px 黑带，8 秒线性扫过全屏
  3. 噪点层：自生成 SVG feTurbulence 噪点（**未使用原站受版权保护的图片素材**），`mix-blend-mode: overlay` + steps(1) 位移抖动，移动端隐藏
  4. gloom 全局微模糊（blur 9px @ 12%）+ 加强版暗角（scale 1.02）
- **跑马灯**：上下线改为 2px，页面载入时从左向右 `scaleX` 展开（对应其 `--marquee-line-scale` 入场）
- **追踪卡升级为「小电视」**：噪点屏幕 + 辉光斜体大编号（`001`–`005` 随分区切换）+ 下方等宽标签；机身配色仍随分区黑/白/荧光黄切换
- **面板圆角**：采用其 `--radius: .5vw` 体系（crt-panel、项目证据板）
- **首屏渐变**：改为其横向青→深蓝方向（`#0e7ea3 → #003c6a → #022a47`）
- 字体保持系统栈：原站的 PP Neue Montreal / Graphik / SemiSqueezed 均为商业授权字体，不可复制文件

## 2026-08-27 晚间补充

- **全站词级 hover**：所有非交互文字（标题/正文/指标/标签/页脚…）都拆成字/词单元，鼠标停到哪个字，哪个字变色+加底色；链接、按钮保留自身的整块反色效果
- **hover 配色按分区区分**（不再全站一个色）：首屏米黄 `#bab5a6` → 灰区荧光黄 → 黑区信号绿 `#0f0` → 宝蓝区浅蓝 `#9fe4f3`
- **轨迹残影扫字效果**：鼠标扫过的字/词即时点亮（字间空白和空格也随之着色，形成连续色带），离开后约 0.3 秒开始、0.55 秒内衰减熄灭——每个单元的计时从被扫到那一刻起算，衰减顺序天然等于扫过顺序。整页只用一个 `mouseover` 事件委托驱动，不给上千个 span 单独绑监听
- 文案微调：去掉牵强的「档案」梗，左下黑牌改为「冯佳炜 · OPEN TO WORK」
- 性能：修复 TreeWalker 边遍历边改 DOM 导致的死循环；CRT 层降耗（去掉全屏 backdrop-filter 与 mix-blend-mode，扫描线改为透明度闪烁），低端设备也能流畅滚动

## 上线路线速查（来自部署对比笔记实测）
